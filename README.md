# Netflix Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python, Pandas, and Matplotlib.

The goal of this project is to clean the dataset, analyze Netflix content, and generate insights through data visualization.

## Tools Used

* Python
* Pandas
* Matplotlib

## Analysis Performed

* Data Cleaning
* Missing Value Handling
* Movies vs TV Shows Analysis
* Top Countries Analysis
* Rating Analysis
* Genre Analysis
* Release Year Trend Analysis

## Key Insights

* Netflix contains more Movies than TV Shows.
* United States contributes the highest amount of content.
* India is the second largest contributor.
* TV-MA is the most common rating.
* International Movies is the most common genre.
* Netflix content production increased significantly after 2015.

## Dataset

Netflix Titles Dataset (2019)
